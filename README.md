# Rose Wood

Rose Wood is a static hotel website. Guests can look through rooms and facilities, check stay dates, and send a message from the contact page.

## Pages

- **About** (`index.html`) — welcome, check-in and check-out dates, guest count, a short introduction, room previews, facilities, and guest testimonials.
- **Rooms** (`rooms.html`) — Standard ($250/night), Deluxe ($270/night), and Luxury ($300/night).
- **Gallery** (`facilities.html`) — 24/7 restaurant, swimming pool, and gym and spa.
- **Contact** (`contact.html`) — address, phone, email, and a message form.

## Run locally

Open `index.html` in a browser. No build step or server is required.

The layout is responsive. On smaller screens, the header uses a menu button, and the room, facility, and testimonial sections use slide indicators.
